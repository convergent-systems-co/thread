# Thread

Thread is the user's memory and orientation layer across projects. Obsidian Markdown notes are the durable backend; no hidden database is authoritative.

Keep capture immediate and independent of AI availability. Preserve original wording, distinguish suggestions from commitments, and attach sources to observations. Missing metrics are unknown, never zero. Repository inspection is read-only. Never equate a recorded Git status with a backup.

Read README.md before extending the CLI. Run `go test -race ./...` and `go vet ./...` for storage or integration changes. Use temporary vaults in tests. Do not inspect the user's original Thread skill or alter Manifold/Praxis/develop as an incidental implementation step.
